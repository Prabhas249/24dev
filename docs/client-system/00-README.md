# 24dev — Client-Ops System (START HERE)

> **This is the hub.** One workspace that runs a 24dev client from their very first
> WhatsApp message all the way to a testimonial, a Care subscription, and a referral.
> Seven docs, one journey. When you're not sure where something lives, come back to this page.

**What 24dev is:** a fast-delivery website agency in India. Solo founder. Sales happen
100% on WhatsApp (Meta ads → Click-to-Chat). Razorpay payments — **50% advance at booking,
50% on delivery.** Two live ads feed this system:

- **Ad 1 — ₹2,000 Starter** (local shops & small businesses): complete site in under 48h, domain + lifetime hosting + starter brand kit + copy included, 1 free revision.
- **Ad 2 — Business from ₹4,999** (serious businesses): 5 tiers — ₹4,999 → ₹9,999 → ₹14,999 → ₹24,999 → ₹49,999. Premium tiers take a few days, not 24–48h.

Everything in these docs is honesty-guarded. We sell **outcomes** (more customers, trust,
found on Google) — never "cheap."

## A. The Client Journey (first WhatsApp → referral)

This is the spine of the whole business. Every doc below plugs into one of these stages.

```
   ┌─────────────────────────────────────────────────────────────────────┐
   │  Meta Ad (Ad 1 ₹2,000  •  Ad 2 from ₹4,999)  →  WhatsApp Click-to-Chat │
   └─────────────────────────────────────────────────────────────────────┘
                                    │
   ① WELCOME ........... instant ack + the right welcome reply ............ [01]
                                    │
   ② DISCOVERY ........ 3 quick questions: business, goal, what they have .. [01]
                                    │
   ③ QUOTE ............ outcome-led pitch, the right tier, add-ons ......... [01] [03]
        │   └─ objections? ("why so cheap", "₹999 elsewhere", "rank #1"…) .. [02]
        │
   ④ 50% ADVANCE ...... Razorpay link → advance received .................. [04]
                                    │
   ⑤ INTAKE ........... single never-blocked intake form (logo/photos/copy) [05]
                                    │
   ⑥ BUILD ............ gated delivery checklist, 24–48h timer starts ...... [05]
                                    │
   ⑦ PREVIEW .......... share staging link, set revision expectations ..... [05]
                                    │
   ⑧ 1 REVISION ....... the one free revision (the guarantee remedy) ...... [05] [06]
                                    │
   ⑨ DELIVER .......... deploy to client's OWN account, domain + SSL, handoff [05]
                                    │
   ⑩ FINAL PAYMENT .... 50% balance Razorpay link + invoice (24DEV/26-27/####) [04]
                                    │
   ⑪ TESTIMONIAL ...... harvest the "live!" peak: screenshot perm + Google review [07]
                                    │
   ⑫ CARE / REFERRAL .. Care plan upsell (₹1,000 / ₹1,999/mo) + ₹500 two-sided referral [07] [03]
```

**The two non-negotiables that make this work:**
1. **Speed at the top** — acknowledge in seconds, quote fast, lock the advance while interest is hot. (Stages ①–④)
2. **The "live!" peak at the bottom** — the moment the site goes live is the single most valuable moment you'll ever have with that client. Harvest proof, Care revenue, and referrals *immediately* — that excitement decays within 48 hours. (Stages ⑪–⑫)

**Honesty checkpoints baked into the journey:** "free logo" = starter brand kit; "free domain" = setup + year 1 (renewal at cost); "free hosting for life" = deployed to the client's own account; SEO = search-ready, rankings depend on Google; AEO = structured for AI assistants, never "guaranteed cited"; ₹49,999 = "from"/MVP scope. These never bend — see [02] and [06].

## C. Daily Operating Loop (the 60-second version)

1. **Lead in?** → fire instant ack [01], qualify with 3 questions [01].
2. **Quoting?** → pick the tier from [03], pitch the outcome [01], crush objections [02].
3. **Yes?** → send 50% advance link [04].
4. **Advance landed?** → send intake form + welcome [05], start the timer.
5. **Building?** → walk the gated checklist [05], move the Kanban card.
6. **Preview → 1 revision → deploy to their account** [05].
7. **Delivered?** → send 50% balance link + invoice [04].
8. **Paid + live?** → grab testimonial + Google review, pitch Care, drop the referral offer [07].

## D. This is a product, not just a process

Everything in this folder — the journey map, the scripts, the objection playbook, the
pricing logic, the payment/invoice SOP, the delivery checklist, the policy templates, and
the retention engine — is a **complete, repeatable operating system for running a
fast-delivery website agency on WhatsApp.** Once 24dev is profitable and the system is
battle-tested on real clients, this same kit can be packaged and sold as an **AgencyOS-style
product** (templates + SOPs + scripts) to other solo founders and small agencies — a second
revenue line built from work you've already done.
