# 05 — Onboarding Intake + 24-48h Delivery SOP

**For:** 24dev founder (solo) — fast-delivery website agency
**Use this when:** an advance has landed and a new project starts, all the way to handoff.

---

## The one rule that protects the 24-48h promise

> **The clock does not start until intake is 100% complete AND the 50% advance is in.**

Speed dies in the gap between "paid" and "started." You can only build as fast as your asset collection is complete. So collect **everything in one form**, up front, in one message — you should never have to send an awkward "hey, can you also send me your logo?" message in the middle of a build.

Define "intake done" once, as a single checklist of *what we need, when, and where to upload it*. Then the build is a clean, uninterrupted run.

---

## (a) THE CLIENT INTAKE FORM

This is the single form you send the moment the advance lands. Keep it short, single-purpose, with file-upload built in and a **"don't have it? skip"** escape on every optional field. Forms hit 70%+ completion when they're short and let people skip what they don't have.

**Delivery options:**
- Build it as a Google Form / Tally / Typeform and paste the link in WhatsApp, OR
- For Ad 1 shop owners: paste the questions directly in WhatsApp and let them reply in one message (pre-fill defaults so they barely type anything).

> **Tip for Ad 1 (shop owners):** Add the line *"Just reply with whatever you have — I'll fill the rest with smart defaults and you approve it in the preview."* This keeps completion high for non-technical owners.

The **#1 same-day blocker is domain/hosting access** — flag it early, resolve it at deploy.

## (c) DELIVERY SOP / CHECKLIST

Each stage has a trigger to enter it and a trigger to exit it. Don't skip gates. This is what protects the promise.

### Gate 0 — Don't start the clock
- [ ] 50% advance confirmed in Razorpay
- [ ] Intake form returned **100% complete** (or all gaps consciously resolved with smart defaults)
- [ ] Scope locked + tier confirmed; any upsells (logo kit, copywriting, extra pages, pSEO) agreed **before** work starts
- [ ] Delivery date stated back to client (24-48h for Starter; "a few days" + exact date for Pro/Commerce/Flagship)

➡️ **Only now does the clock start.** Move card to **In Progress**.

### 1. Design
- [ ] Pick template/base matched to tier + their "sites I like" references
- [ ] Lay out structure (sections/pages) per scope
- [ ] Drop in logo, brand colours, fonts
- [ ] **Structure approved** (internal gate — does it match scope?) ✅ exit trigger

### 2. Build
- [ ] Copy in (their content, or your drafted copy)
- [ ] Images optimized + **alt text** added
- [ ] Mobile / responsive check (phone + tablet)
- [ ] Forms tested (contact / enquiry / WhatsApp click-to-chat button works)
- [ ] SEO basics: page titles, meta descriptions, sitemap, schema markup
- [ ] Speed check (compress assets, lazy-load images)
- [ ] For Commerce tier: payment (Razorpay) test transaction passes
- [ ] **Self-QA pass complete** ✅ exit trigger

### 3. Preview
- [ ] Deploy to **staging/preview URL**
- [ ] Send preview message (template below)
- [ ] **Approval SLA stated:** "Reply with changes within [X hours], or I publish this version" — so client delay never breaks your clock

### 4. The 1 free revision (scoped)
- [ ] Collect ALL revision notes in **one** reply (state this clearly — kills the back-and-forth loop)
- [ ] The free revision is a **fixed deliverable**, not open-ended — present the site as a finished product, not a draft to endlessly tweak
- [ ] Apply changes → re-check mobile + forms
- [ ] Send updated preview → get **final approval** ✅ exit trigger
- [ ] Further rounds beyond the 1 free = quoted as a small change request (protect your time)

### 5. Deploy (to the client's OWN account)
- [ ] Deploy to the **client's own hosting account** (free-for-life lives on *their* account — you own nothing, they own everything)
- [ ] Hand over hosting access / confirm it's under their login

### 6. Connect domain
- [ ] If they own a domain → point DNS (A / CNAME records) or via delegated registrar access
- [ ] If you registered it → confirm it's in **their name** with year-1 paid; note renewal-at-cost in handoff doc
- [ ] Confirm www + non-www both resolve

### 7. SSL
- [ ] Enable SSL/HTTPS (Let's Encrypt / host-provided)
- [ ] Verify padlock shows on the live domain
- [ ] Force HTTPS redirect (no mixed-content warnings)

### 8. Handoff
- [ ] Send the live URL + handoff doc
- [ ] Handoff doc contains: "**you own everything**" statement, hosting account details, domain + renewal note, how to edit basics, what the 1 free revision covered, and the Website Care offer (Rs 1,000/mo Starter, Rs 1,999/mo Business+)
- [ ] **Collect final 50%** via Razorpay
- [ ] Move card to **Delivered**

### 9. Post-launch watch (48-72h)
- [ ] Monitor 48-72h for: 404s, form submission failures, Search Console crawl errors
- [ ] Quick "everything good?" check-in → ask for a (genuine) review/testimonial
- [ ] Only **after** this clean window → move card to **Closed**

> ⚠️ **Honesty guardrails at handoff:**
> - Domain renewal = **at cost**, stated in writing.
> - Hosting = on **their** account; "free for life" means no fee *from us*, on infrastructure they own.
> - SEO = "search-ready," not "guaranteed #1."
> - AEO (if sold) = "structured so AI assistants can find you," never "guaranteed cited."
> - Rs 49,999 Flagship/app = "from"/MVP scope — state what's in v1.

## Where this plugs into the 24dev admin Projects Kanban

The 6 lanes map 1:1 to the gates above. Each card moves left→right; the **exit trigger** of a stage is what lets you drag the card forward.

| Kanban lane | SOP stage(s) | Card moves forward when… |
|---|---|---|
| **New / Booked** | Gate 0 | Advance landed (Razorpay webhook) + intake form sent |
| **Intake** | Gate 0 | Intake returned 100% + scope/tier locked + clock started |
| **In Progress** | 1 Design → 2 Build | Self-QA pass complete |
| **Preview / Review** | 3 Preview → 4 Revision | Final approval received |
| **Deploy** | 5 Deploy → 6 Domain → 7 SSL → 8 Handoff | Live + SSL verified + final 50% collected |
| **Delivered → Closed** | 9 Post-launch watch | Clean 48-72h window passed; review requested |

**Automation hooks (existing webhook layer):**
- Razorpay **advance** webhook → auto-create card in **New / Booked** + auto-send the welcome message + intake link.
- Intake form submission → flip card to **Intake** and surface answers on the card (so scope/upsells are visible at a glance).
- Razorpay **final 50%** webhook → flip card to **Delivered**.
- A simple 72h timer from "Delivered" → reminder to run the post-launch watch + request the review, then **Closed**.

> Keep the intake answers attached to the card. When you sit down to build, everything you need is on one screen — that's the whole point: **never blocked, clock never stops.**
