## (earlier) FORMAT DECISION: all 3 ads ship as 5-CARD CAROUSELS
User call: each ad = 5 swipeable 1:1 cards (1080×1080), English only. Structure per ad:
- **Card 1** = hook · **Card 2** = what you get / how it works · **Cards 3-5** = PORTFOLIO, one full one-page site per card (phone frame + business name + delivery time), last card carries the CTA.
- 3 ads × 5 cards = **15 cards total** (= the "10-15/day" showcase). Swap the 3 portfolio sites for fresh shipped work daily.

- Every card's CTA = Send WhatsApp Message.
- Data: cost-per-conversation per CAROUSEL (June 19 read) + clicks per CARD (Breakdown → By Carousel Card → tells you which portfolio site pulls most taps → make more like it).
