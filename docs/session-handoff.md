## 🤖 Claude co-pilot strategy

### The vision
Claude is **co-employee**, not replacement. 2-tier AI stack:
- **Claude Haiku/Sonnet** for quality (drafts, routing, decisions)
- **DeepSeek** considered for cheap internal monitoring only (DPDP compliance concern for client data)
- **RAG over custom fine-tune** — store 24dev knowledge in Supabase, retrieve per message

### Autonomy tiers
- **AUTO:** FAQ replies, payment confirmation, deploys, Lighthouse checks, Kanban status updates
- **SUGGEST:** Sales replies, ad creative pause, budget increase, refunds, scope changes, complaint handling, first-pass site builds
- **NEVER:** Refund execution, firing, contract signing, pricing changes

### 10 use cases (from feedback — ranked by build order)
**Weekend 2 (ship):**
1. WhatsApp draft replies
2. Daily 9am brief via WhatsApp
3. Scope creep detection (match incoming vs signed scope)
4. Post-delivery 7-day followups
5. Project timer intelligence (smart escalation)

**Weekend 3:**
6. Meta ads monitoring + alert engine
7. Client psychology tone (rule-based v1)
8. Ad creative feedback loop (builds as data flows)
9. Weekly founder review (Sunday digest)
10. Employee layer (role perms + dedicated inbox)

### Critical build principles
- **Prompt caching aggressive** — client context stays, only new message variable (saves 70-80% on API cost)
- **Audit log every Claude action** to `claude_actions` table (input, output, user decision, outcome)
- **Start SUGGEST only** — auto-execution promoted gradually from real patterns
- **Friction log tells us what to automate** — automate from REAL repetition, not imagined
